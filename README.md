# ICT — Технологии промышленной чистоты

Адаптивный одностраничный сайт промышленного клининга с модальными окнами услуг, админ-панелью для замены фотографий с автоматической конвертацией в **WebP** и редактором перечня услуг и дополнительных работ.

## Структура проекта
- `index.html`, `css/styles.css`, `js/app.js` — основной одностраничный сайт (Desktop + Mobile).
- `admin.html`, `css/admin.css`, `js/admin.js` — админ-панель:
  - **Вкладка 1 (Фотографии и WebP):** загрузка фото Hero и пар «До/После» с автоматическим ресайзом и конвертацией в `.webp` в браузере.
  - **Вкладка 2 (Услуги и доп. работы):** редактирование списков «Что входит», «Что не входит» и таблицы доп. работ (`от {цена} руб./{единица}`).
- `admin/api/` — готовые PHP-обработчики (`upload.php`, `save-services.php`) для переноса на классический PHP-хостинг (Beget, Timeweb, Reg.ru).
- `data/site-config.json` — контакты, гарантии, FAQ и реквизиты.
- `data/media.json` — пути к WebP-фотографиям.
- `data/services.json` — перечень всех 8 услуг и дополнительных работ.
- `AGENTS.md` — правила работы для ИИ-агента.

## Настройка PHP-хостинга (если размещаете не на GitHub Pages)
1. Скопируйте `admin/api/config.example.php` в `admin/api/config.local.php`.
2. Сгенерируйте хеш своего пароля: `php -r "echo password_hash('ВашПароль', PASSWORD_DEFAULT);"` и вставьте его в `password_hash`.
3. В админ-панели выберите режим **PHP-хостинг** и введите пароль.

## Работа через GitHub Pages
1. Включите GitHub Pages в настройках репозитория (`main` / root).
2. В `admin.html` выберите режим **GitHub API**, укажите репозиторий и свой GitHub Personal Access Token (токен хранится только в вашем браузере и не попадает в код).
